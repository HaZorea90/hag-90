# תוכנייה דיגיטלית – חג הקיבוץ, 90 שנה להזורע

עמוד אחד שמציג לקהל את התוכנייה של חג הקיבוץ (יום שישי, 2.10.2026, 20:30, האולם).
כתובת: https://hazorea90.github.io/hag-90/

האתר סטטי לגמרי (`index.html`, `style.css`, `app.js`). התוכן נמשך בכל טעינה מהגיליון "תוכנייה – גרסה ציבורית".

## עדכון תוכן

כל התוכן נערך **בגיליון בלבד**, בלי לגעת בקוד. יש בו שש לשוניות, והשורה הראשונה בכל לשונית היא כותרות העמודות. אסור לשנות את הכותרות:

| לשונית | עמודות | מה לשים לב |
| --- | --- | --- |
| settings | key, value | מפתחות: title, subtitle, date, time, place, thanks_title |
| program | order, title, type, leads, song, description | order הוא מספר וקובע את הסדר. שורה בלי title לא מוצגת |
| participants | section, name, role | section חייב להיות זהה בדיוק ל-title של הקטע ב-program, או "קטעי קישור" |
| team | group, name, role | group הוא אחד מאלה: צוות החג, תפאורה ואביזרים, תאורה והגברה |
| thanks | text | כל שורה בגיליון היא פסקה |
| lyrics | song, credits, lyrics | כל המילים בתא אחד. בין בתים משאירים שורה ריקה (Ctrl+Enter / ⌘+Enter בתוך התא) |

- הגיליון מפורסם לאינטרנט, כך ש**כל מה שכתוב בו גלוי לכולם**. לא לכתוב בו טלפונים, הערות פנימיות או סימני שאלה ליד שמות.
- חלק שאין בו תוכן (למשל תודות ריקות) פשוט לא מוצג.
- שינוי בגיליון מופיע באתר תוך כמה דקות. גוגל שומרת עותק זמני של הגיליון המפורסם, ולכן לפעמים צריך לחכות ואז לרענן.

## קישורי הגיליון

קישורי ה-CSV נמצאים בבלוק `CONFIG` בראש `app.js`. כדי לקבל קישור: קובץ › שיתוף › פרסום באינטרנט › בוחרים לשונית › "ערכים מופרדים בפסיקים (csv)" › פרסום. חוזרים על זה לכל אחת משש הלשוניות.

## גיבוי (data.json)

אם הגיליון לא נטען תוך 4 שניות, או שהטעינה נכשלת, העמוד מציג את העותק השמור `data.json` עם ההודעה "מציג גרסה שמורה".
**לפני העלייה לאוויר, ואחרי כל שינוי גדול בגיליון**, מרעננים את העותק (נדרש Node 18 ומעלה):

```bash
node scripts/fetch-data.js
git add data.json && git commit -m "רענון data.json" && git push
```

אם אחד הקישורים שבור, הסקריפט עוצר ולא דורס את data.json.

## הרצה מקומית

```bash
python3 -m http.server 8000
```

ואז פותחים בדפדפן את http://localhost:8000. אי אפשר לפתוח את `index.html` ישירות מהקובץ, כי הדפדפן חוסם את טעינת הנתונים.

## העלאה (GitHub Pages)

בריפו `hag-90` בחשבון `hazorea90`: Settings › Pages › Source: Deploy from a branch › `main` / `(root)`. כל push ל-`main` מתעדכן באתר תוך דקה-שתיים.

## הורדת האתר אחרי האירוע

1. בריפו: Settings › Pages › Unpublish site. אפשרות נוספת היא למחוק את הריפו, או להפוך אותו לפרטי.
2. בגיליון: קובץ › שיתוף › פרסום באינטרנט › הפסקת הפרסום.
3. לבטל את הקישור המקוצר, אם נוצר.
