# תוכנייה דיגיטלית - חג הקיבוץ, 90 שנה להזורע

עמוד אחד שמציג לקהל את התוכנייה של חג הקיבוץ (יום שישי, 2.10.2026, 20:30, האולם).
כתובת: https://hazorea90.github.io/hag-90/

האתר סטטי לגמרי (`index.html`, `style.css`, `app.js`), בלי שלב בנייה. כל התוכן נמצא בקובץ `data.json`.

## עדכון תוכן

עורכים את `data.json`. יש בו חמש לשוניות (`tabs`), וכל אחת היא טבלת CSV בתוך מחרוזת. השורה הראשונה בכל לשונית היא כותרות העמודות, ואסור לשנות אותן:

| לשונית | עמודות | מה לשים לב |
| --- | --- | --- |
| settings | key, value | מפתחות: title, subtitle, date, time, place, thanks_title |
| program | title, name, credits, participants | שורה לכל קטע, לפי סדר ההופעות. title היא הכותרת (למשל "קטע ראשון"), name הוא שם הקטע, credits הם מי כתב, ו-participants הם מי השתתף (מוצגים כשפותחים את הכרטיס). בתא עם כמה שורות, כל שורה מוצגת בנפרד. שורה שנגמרת ב-":" או ב-"-" מוצגת ככותרת קטנה. שורה בלי title לא מוצגת |
| team | group, name, role | group הוא אחד מאלה: צוות החג, תפאורה ואביזרים, תאורה והגברה. שם שנגמר ב-":" (למשל "בעזרה של:") מוצג ככותרת קטנה בתוך הרשימה |
| thanks | text | כל שורה היא פסקה |
| lyrics | song, credits, lyrics | כל המילים בתא אחד. בין בתים משאירים שורה ריקה |

- הריפו ציבורי, כך ש**כל מה שכתוב ב-`data.json` גלוי לכולם**. לא לכתוב בו טלפונים, הערות פנימיות או סימני שאלה ליד שמות.
- חלק שאין בו תוכן (למשל תודות ריקות) פשוט לא מוצג.
- אחרי כל שינוי ב-`style.css` או ב-`app.js` מעלים את המספר שאחרי `?v=` בשני הקישורים ב-`index.html`. אחרת טלפונים עלולים להציג קבצים ישנים מהזיכרון.

## חיבור לגיליון גוגל (לא בשימוש כרגע)

`app.js` יודע למשוך את אותן חמש לשוניות מגיליון גוגל שפורסם לאינטרנט כ-CSV. מדביקים את הקישורים בבלוק `CONFIG` בראש הקובץ, ומאותו רגע `data.json` משמש כגיבוי: הוא מוצג עם ההודעה "מציג גרסה שמורה" אם הגיליון לא נטען תוך 4 שניות. הפקודה `node scripts/fetch-data.js` מרעננת את הגיבוי מהגיליון.

## הרצה מקומית

```bash
python3 -m http.server 8000
```

ואז פותחים בדפדפן את http://localhost:8000. אי אפשר לפתוח את `index.html` ישירות מהקובץ, כי הדפדפן חוסם את טעינת הנתונים.

## העלאה (GitHub Pages)

בריפו `hag-90` בחשבון `hazorea90`: Settings › Pages › Source: Deploy from a branch › `main` / `(root)`. כל push ל-`main` מתעדכן באתר תוך דקה-שתיים.

## הורדת האתר אחרי האירוע

1. בריפו: Settings › Pages › Unpublish site. אפשר גם למחוק את הריפו או להפוך אותו לפרטי.
2. לבטל את הקישור המקוצר, אם נוצר.
